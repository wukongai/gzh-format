# 可编辑预览与保存独立夹具验收

本次只验证本地代码及独立文章,未读写 Harness 实稿,未调用真实微信接口或读取凭证,未 commit/push/发布。真实文章由用户另选后验收。

## 归档口径（2026-10-25）

用户本轮认可开发任务可归档；本报告仍只证明下列独立夹具与浏览器证据，不升级为真实文章或微信端验收。交付范围见[本地变更记录](../../CHANGELOG.md),后续使用边界见[编辑保存说明](../../references/editable-preview.md#独立夹具验证)。v0.27.0 / gzh-format 0.5.0 仍本地未发布。本报告随独立 Skill 包分发,主仓规格、计划和日志从各自入口回链此报告,不作为包内运行依赖。

默认交付已做只读合同核对：用户只说“公众号排版这篇 md”，minimal 且来源可可靠映射时直接走 `wrap --editable --source-md` 与 `serve --manifest`，交付可编辑、可保存 URL；只读例外及同步独立授权见[使用说明](../../references/editable-preview.md#打开能直接保存的预览)。该场景核对没有新增真实文章或微信测试。

## 浏览器与磁盘验收

预览页面真实输入、删除、选区跨 span/链接与跨段操作,红色/粗体四组合独立,撤销重做与中文 IME 提交均保持文字。标题编号与图片区域受保护。首开保留 renderer 外观,换行在编辑、预览和复制时可见。

首轮曾验证下载修改包与兼容导入。作者验收后,最终流程改为单一“保存草稿”,不需要导出。新整页端到端用 16 张独立图片、11 个 H3 编号的专用源文,点击保存实际快照回填,撤销已保存删段再保存恢复,重做再保存删除,重开 revision 3。最终正文无工具条、脚本、连接令牌或 contenteditable；图序与编号保持。

单文章 HTTP 服务验证 127.0.0.1 绑定、同源 Origin、准确 Host、随机令牌、精确路由与请求体上限。恶意字段、跨站/错误身份、来源漂移和文件重新绑定均零写入。会话保持稳定块身份,保存后撤销可以恢复删除段落及其原链接。保存不清客户端 history,保存期间新输入保持未保存,未知确认失败保留页面与原提交供安全重试。

导入器覆盖 CRLF 原始字节备份、未编辑片段保留、无编辑不制造源变化、同包幂等、来源漂移/危险链接/未知字段零写入、保存中断恢复且可重试、自定义预览路径刷新及软链路径冲突拒绝。同步元数据登记绑定实际发送时身份,拒绝正文、非白名单元数据和复杂多行 YAML 混淆。

## 已知边界

仅 minimal 确定性渲染且来源可重现时支持回填。无可靠映射的自动问题/示例组、双链块、图片、代码、表格和固定页尾只读。直接保存页须由本机服务打开,旧 file:// 页无连接时禁用保存。页面关闭重开后保留磁盘稿,不承诺撤销历史跨重开。预检只能看到已保存磁盘修订,不能探测浏览器尚未保存的内容;旧修改包仍可通过兼容导入处理。

此报告不是远端微信回读或真实任务效用认证。现有三方比较与原 ID update 仍由同步合同负责,不提供通用自动合并。
